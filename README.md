# RankShorts Studio

Editor web para crear Shorts de rankings (Top 5, cuenta atrás) en 1080×1920, directamente en el navegador.

- Título y textos editables, también haciendo clic sobre el vídeo
- Clips propios (vídeo o imagen) con recorte, encuadre, zoom y audio
- Plantillas de estilo, gancho inicial, música de fondo
- Exporta MP4 (o WebM según el navegador) y portada PNG
- Generador de títulos, descripción, hashtags y comentario fijado

Todo se procesa en local: los clips no se suben a ningún servidor; se guardan en el navegador (IndexedDB).

Para usarlo en el ordenador sin internet: `abrir.bat` (necesita Python).
